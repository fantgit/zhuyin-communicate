# 注音溝通板

給手指沒力、點不準的孩子和長輩用的注音打字溝通工具。照「聲母 → 介音 → 韻母 → 聲調」一步一步拼，拼完選國字，按「唸出來」就會用中文語音唸出來。iPad 和手機都能用，加入主畫面之後沒有網路也能打開。

網址：https://fantgit.github.io/zhuyin-communicate/

> 這個專案原本是「眼睛注音板」（相機眼控）。2026 年 11 月改成純觸控版，眼控、相機和校正功能已經完全移除，舊版留在 git 歷史裡。

## 手指沒力、點不準也能選對

| 設計 | 怎麼幫忙 |
|---|---|
| **放開才選**（預設） | 手指先放上去，被按到的格子會下沉、亮框。點偏了不用重按，滑到對的格子再放開就好 |
| 手指上方放大顯示 | 手指會遮住格子，所以在手指上方跳出正要選的字 |
| 抬手時的手滑不算 | 放開那一下滑到隔壁格，仍然算手指原本停住的那格；很快的一點，以剛碰到的那格為準 |
| 縫隙就近吸附 | 點在格子之間的縫隙或格子外不遠處，算最近的格子，不會按了沒反應 |
| 防手抖連按 | 選到一格之後 0.4 秒內再碰到都不算（設定裡可調 0–1.5 秒） |
| 取消 | 手指滑到上方打字列再放開，就不會選 |
| 手掌誤觸 | 先放著的手指或手掌不算，最後碰到的那根手指才算；接觸面很大的碰觸當成手掌 |

設定裡還有另外兩種選法：

- **按住才選**：停在格子上一段時間（0.3–2 秒）才算，適合常常不小心碰到、劃過去的人。按住時短暫滑出格子再回來，進度不會歸零。
- **一碰就選**：以第一下碰到的格子為準，適合手指一放上去就會滑走的人。

## 怎麼打字

- 第一步選聲母那一組（例如 ㄅㄆㄇㄈ），再選符號；沒有聲母的字（例如「我」ㄨㄛˇ）選「沒有聲母」。
- 第二步選介音或韻母。拼不出來的符號會變淡，按了也不會選（例如 ㄐ 後面不能接 ㄨ）。
- 第三步選聲調，每個聲調格子會顯示例字。
- 第四步選國字，字下面有提示詞（媽 → 媽媽），避免選到同音字。
- 正在拼的注音會接在上方打字列的最後面，用底色標出來。
- 右邊（直放時在下面）三顆固定鍵：**退回**（每按一次退一步）、**唸出來**、**更多**。
- 「更多」裡有標點、空格、常用句、大字給人看、全部清除，以及設定。

## 設定

在「更多」裡**按住「按住開設定」一秒**才會打開，孩子不會誤開。可以調整：

- 怎樣才算選到（放開才選、按住才選、一碰就選）、要按住多久、防止手抖連按的時間、手指上方放大顯示
- 注音鍵盤：大格分兩步選（預設，一頁最多 8 格），或一頁看到全部注音（格子比較小）
- 文字大小、低刺激模式（顏色變淡、沒有動畫）
- 打出國字或只打注音、拼不出字的注音變淡、國字上方顯示注音、選完字先猜下一個字
- 選注音和選字時唸出來、提示音、說話速度
- 常用句（最多 12 句，選到會直接唸出來）

設定和打出來的字只存在這台裝置的瀏覽器裡，不會上傳；手機和平板要各自設定。

## 加入主畫面、離線使用

1. 用 Safari（Android 用 Chrome）打開網址 → 分享 › 加入主畫面。
2. **從主畫面圖示**打開一次，保持連網一分鐘，鍵盤、字典和字型就會存進裝置。之後沒有網路也能打開。
3. 從主畫面打開是全螢幕，沒有網址列，注音格子會更大。
4. 改版之後，只要連網打開一次，下次打開就是新版。

手機請直著拿，鍵盤用「大格，分兩步選」，文字大小用「標準」，格子會最大。

## iPad／iPhone 建議設定

1. **中文語音**：設定 › 輔助使用 › 朗讀內容 › 聲音 › 中文 → 下載「美佳（台灣）」的加強版聲音，唸起來比較自然。
2. **引導使用模式**（建議）：設定 › 輔助使用 › 引導使用模式 → 開啟。打開本工具後連按三下側邊或頂端按鈕，孩子就不會跳出去。
3. 按「唸出來」沒有聲音時，先確認沒有開靜音、音量有開。

> 選單名稱是依據 iOS／iPadOS 18 的一般寫法，裝置上的實際名稱可能略有不同。

## 自己架站

執行 `python3 tools/build.py` 會產生 `docs/` 和 `zhuyin-communicate-site.zip`，放到任何 https 靜態網站服務就可以：

- **GitHub Pages**：Settings › Pages 選「Deploy from a branch」→ `main` / `/docs`。
- **Netlify Drop**：把 `docs` 資料夾拖到 app.netlify.com/drop。
- **Cloudflare Pages**：上傳 `docs/`。

## 測試

```
pip install playwright pillow && playwright install chromium
python3 tools/build.py
python3 test/e2e.py
```

測試會在本機開一個伺服器，用模擬觸控檢查拼字、滑動修正、抬手手滑、取消、防連按、三種選法、設定要按住才開、離線打開，並把截圖存到 `test/shots/`。

## 設計依據

| 決定 | 依據 | 可信度 |
|---|---|---|
| 放開才選、按住才選、一碰就選、防連按 | 和 iOS 輔助使用「觸控調整」的「按住持續時間」「忽略重複」「點按輔助（使用最初／最後觸碰位置）」是同一類作法 | 原則性建議 |
| 每頁最多 8 格、格子位置固定，拼不出來的變淡、不移除 | 固定的空間位置和用顏色分群能幫助在溝通板上找符號（Light 等 2019，AAC 版面設計綜述） | 可能正確 |
| 聲母藍、介音綠、韻母黃、聲調紫，低彩度；可切換低刺激 | 同上。只用柔和的類別色 | 可能正確 |
| 不閃爍、沒有倒數、沒有失敗音效 | 一般感官友善設計原則 | 原則性建議 |

## 已知限制

- 觸控判斷是在電腦瀏覽器上用模擬觸控測試的，還需要在實際的 iPad 和手機上試用，依孩子的情況調整選法和時間。
- 單獨唸注音符號是借用同音字（例如 ㄅ 唸「玻」），少數符號（ㄝ、ㄥ）聽起來可能不夠標準。
- 字典來自新酷音（libchewing）詞庫，依使用頻率排序，每個音最多 12 個字，並過濾成 Big5 字元，但仍可能留有少數罕用字。
- 「唸出來」只打注音時，是用同音最常用字給語音引擎唸。少數破音字可能唸錯聲調。
